# Windows 轻量待办提醒桌宠

> 基于 Tauri 2（Rust 后端 + 原生 HTML/CSS/JS 前端）的 Windows 桌面悬浮桌宠软件。
> 纯本地运行、极致低内存、单 EXE 打包免安装。

***

## 核心功能

### 1. 悬浮桌宠

| 特性     | 说明                           |
| ------ | ---------------------------- |
| 透明无边框  | 背景完全透明，不显示在任务栏和 Alt+Tab      |
| 可拖拽    | 鼠标拖动桌宠到任意位置，自动边界检测不越界        |
| 不抢焦点   | ToolWindow 样式，永不抢占输入焦点       |
| 可缩放    | 支持 0.5x \~ 2.0x 缩放，气泡和菜单同步缩放 |
| 最小化到托盘 | 关闭窗口不退出，隐藏到系统托盘              |

### 2. 待办管理

| 功能      | 说明                                                  |
| ------- | --------------------------------------------------- |
| 完整 CRUD | 创建、查看、编辑、删除待办事项                                     |
| 字段支持    | 标题、内容、截止时间、优先级（高/中/低）、完成状态                          |
| 筛选查看    | 按状态筛选（全部/未完成/已完成）                                   |
| 本地存储    | SQLite 数据库，数据存储在 `%LOCALAPPDATA%\WindowsPet\pet.db` |

### 3. 智能提醒

| 场景   | 触发条件                              |
| ---- | --------------------------------- |
| 空闲提醒 | 系统空闲超过设定时间 + 有未完成待办 + 未锁屏 + 无全屏应用 |
| 每日提醒 | 到达设定时间（默认 09:00）提醒创建今日待办          |
| 延后提醒 | 点击"延后 10 分钟"按钮，暂缓提醒               |
| 冷却机制 | 两次提醒之间有最小间隔，防止频繁打扰                |

### 4. 状态机动画

| 状态          | 触发条件        | 动画效果       |
| ----------- | ----------- | ---------- |
| Idle        | 默认状态        | 轻微晃动 + 眨眼  |
| Remind      | 空闲提醒触发      | 踱步 + 抖动    |
| Talk        | 左键点击        | 打招呼 + 显示气泡 |
| Sleep       | 15分钟无操作且无待办 | 休眠降帧       |
| Interactive | 点击打招呼       | 短暂挥手动画     |

### 5. 交互方式

| 操作   | 效果                        |
| ---- | ------------------------- |
| 左键点击 | 显示气泡：打招呼 + 未完成待办列表        |
| 右键点击 | 显示菜单：待办管理 / 设置/ 隐藏 / 退出   |
| 托盘左键 | 显示/隐藏桌宠                   |
| 托盘右键 | 菜单：显示/隐藏 / 待办管理 / 设置 / 退出 |

### 6. 设置选项

| 设置项    | 说明                |
| ------ | ----------------- |
| 空闲提醒超时 | 1\~720 分钟，默认 5 分钟 |
| 提醒冷却间隔 | 5\~3600 秒，默认 30 秒 |
| 每日提醒时间 | HH:MM 格式，默认 09:00 |
| 开机自启   | 注册表 HKCU Run      |
| 窗口置顶   | 始终保持在最前           |
| 缩放比例   | 0.5x \~ 2.0x      |
| 提醒音效   | 开关（当前为简单提示音）      |

## 快速开始

### 环境准备

1. **Rust 工具链**（1.70+）：<https://rustup.rs/>
2. **WebView2 运行时**：Win10/11 一般自带
3. **Node.js**（16+）：<https://nodejs.org/>
4. **Visual Studio Build Tools**：MSVC v143 + Windows SDK 10/11

### 运行开发版

```powershell
# 安装依赖
npm install

# 生成图标
node generate-icons.js

# 开发模式运行
npm run dev
```

### 编译打包

```powershell
npm run build
```

输出位置：`src-tauri/target/release/`

- `WindowsPet.exe`：单文件可执行
- `bundle/nsis/WindowsPet_1.0.0_x64-setup.exe`：安装包

## 技术亮点

| 特性          | 实现方式                                    |
| ----------- | --------------------------------------- |
| 极低内存占用      | 纯 SVG + CSS 动画，无 JS 框架                  |
| 单 EXE ≤15MB | Tauri 默认瘦体积，rusqlite bundled            |
| 透明窗口无黑边     | WS\_EX\_LAYERED + WebView2 合成           |
| 不抢焦点        | WS\_EX\_TOOLWINDOW + WS\_EX\_NOACTIVATE |
| 空闲检测精准      | GetLastInputInfo 每秒轮询                   |
| 多显示器支持      | current\_monitor + work\_area clamp     |
| 开机自启        | HKCU Run 注册表                            |

***

## 开发注意事项

1. **透明窗口**：不使用 Win32 分层颜色键，依赖 WebView2 合成
2. **焦点管理**：所有窗口 `focus: false`，避免抢占输入
3. **空闲检测**：每秒 tick，避免重计算
4. **注册表权限**：只写 HKEY\_CURRENT\_USER，无需管理员权限
5. **多显示器**：`window_clamp_position` 按当前显示器工作区夹紧
6. **重复提醒**：冷却时间 + 延后机制双保险
